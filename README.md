# 🚌 MYMap - Public Transport Navigation

A Google Maps alternative focused on public transport routing,
especially for areas where standard maps fail to show transit options.

## 🎯 Problem Solved
Google Maps shows "Cannot seem to find a way there" for many rural 
destinations. TransitMap provides detailed bus routes, stops, timings,
and fare information.

## ✨ Features
- 🗺️ Interactive map with OpenStreetMap
- 🚌 Public transport routing (KSRTC buses)
- 🚗 Car driving directions
- 🚶 Walking routes  
- 🚏 Nearby bus stops finder
- 💰 Fare information
- 📞 Transport helpline contacts
- 📱 Mobile-first design

## 🛠️ Tech Stack
- **Frontend**: React + Vite + Leaflet.js + Tailwind CSS
- **Backend**: Node.js + Express
- **Maps**: OpenStreetMap (Free)
- **Routing**: OSRM (Free)
- **Geocoding**: Nominatim (Free)
